# Excel Sales Data Analysis

Analyzing sales data using Microsoft Excel to identify trends, compare performance, and support data-driven decisions.

## Project Overview

This project uses Microsoft Excel to analyze sales data and evaluate business performance. An interactive dashboard was created to summarize key performance indicators and visualize trends across profit, products, countries, and sales segments.

## Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

* **Total Sales:** Overall sales revenue.
* **Total Profit:** Overall profit generated.
* **Total Units Sold:** Total quantity of units sold.
* **Total Products Sold:** Product sales metric tracked in the dashboard.

## Analysis and Visualizations

The dashboard includes the following analyses:

* **Monthly Profit Trend:** Tracks how profit changes over time.
* **Units Sold by Product:** Compares the number of units sold across products.
* **Top 5 Countries by Sales:** Highlights the five highest-performing countries by sales.
* **Top 5 Selling Products:** Identifies the top five products based on sales performance.
* **Sales by Segment:** Compares sales across different customer segments.

## Tools Used

* Microsoft Excel
* Data analysis and visualization
* Charts and graphs
* Dashboard reporting

## Key Insights

The dashboard helps identify monthly profit trends, compare product performance, highlight leading countries by sales, and understand how sales are distributed across customer segments.

These analyses provide a useful overview of business performance and support data-driven decision-making.
